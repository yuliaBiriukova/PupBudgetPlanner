I-019 · Keypad with round keys
Scheme

The phone's keypad under the transaction form (F-018), as it is today and with round keys. Only the keys' shape changes: same colours, the same order. Today and A keep the 52 px rows; B's circles need 60 px, so its keypad is 32 px taller.

The keys work: type an amount, + and − add up, ⌫ removes the last digit.
