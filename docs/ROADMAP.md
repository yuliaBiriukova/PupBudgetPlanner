# Roadmap

MVP first, deployed and usable by our family; then expand. Each milestone ends with a working,
deployed app. Tasks for each milestone are in [BACKLOG.md](BACKLOG.md).

## MVP

| # | Milestone | Outcome | Status |
|---|-----------|---------|--------|
| M0 | Foundation | Repo, docs, scaffolded backend + frontend, Storybook, CI, "hello world" deployed to Render + Neon, hosting risks verified | In progress |
| M1 | Authentication & app shell | Sign up / sign in (email + password, Google), app layout & navigation | Todo |
| M2 | Accounts & categories | Default categories per user, accounts with opening balances, balances overview | Todo |
| M3 | Transactions | Quick add expense / income / transfer (incl. currency exchange), list, edit, delete; NBU rates | Todo |
| M4 | Reports | Monthly and yearly reports like the spreadsheet, report currency | Todo |
| M5 | Family | Create family, invite link, member / combined views | Todo |
| M6 | MVP release | PWA, polish, full E2E coverage, production launch | Todo |

## After MVP

| # | Milestone | Outcome |
|---|-----------|---------|
| M7 | Quality | Integration tests with Testcontainers in CI |
| M8 | Email | Resend: email confirmation, password reset, invitations by email |
| M9 | Privacy & categories | Private accounts / transactions; add / rename / reorder / remove categories |
| M10 | Data import | Spreadsheet history 2024–2026, Monefy CSV |
| M11 | Insights | Dashboard with charts, budgets per category, Excel export |
| M12 | Localization | Ukrainian UI |
| M13 | Automation | Monobank API auto-import of card transactions |

Order after the MVP will be agreed when we get there.
